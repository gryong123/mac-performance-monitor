# 性能监测

一个默认出现在 macOS 主屏幕左下角、可自由拖动的轻量电脑性能监测面板。

## 开发运行

```bash
swift run PerformanceMonitor
```

开发运行模式可以预览面板，但系统通知和登录启动不可用。

## 生成本地应用

```bash
bash scripts/build-app.sh
open dist/PerformanceMonitor.app
```

首次打开本地 `.app` 时，系统可能询问通知权限。通过菜单栏中的仪表图标可以打开设置、隐藏面板或退出应用。

## 当前能力

- CPU、内存、磁盘、网络、电池和高占用进程前 6 项实时监测
- 1 小时、24 小时和 7 天 CPU/内存趋势
- SQLite 本地历史记录与 7 天自动清理
- 连续高负载告警
- 首次显示在主屏幕左下角，可拖动并记住位置
- 按住面板顶部 64pt 标题区域进行拖动，即使面板处于桌面层也能移动
- 固定面板尺寸，屏幕变化后自动保持在可见区域
- GPU、温度和风扇使用安全降级状态，等待只读辅助程序接入
