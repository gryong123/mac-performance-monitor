# 测试标准

## 窗口

- 面板左边与主屏可用区域相距 16pt。
- 面板底边与主屏可用区域相距 16pt。
- Dock 在左、右、下方时均不重叠。
- 按住顶部标题区域可拖动面板，重新启动后恢复上次位置。
- 面板未激活、Finder 桌面处于前台时，顶部标题区域仍可拖动。
- 分辨率、主显示器、Space 变化后保持在可见区域。
- 普通应用窗口可覆盖面板，面板不可缩放。

## 数据

- 采样失败显示 0 或“暂不可用”，应用不崩溃。
- 网络第一次采样为 0，后续显示速率。
- 进程列表只读且不包含本应用。
- 同一分钟只有一条历史记录。
- 7 天以前的历史被清理。

## 告警与设置

- 连续 3 次超过阈值才进入“过高”状态。
- 15 分钟内不重复发送通知。
- 修改阈值后重启应用仍保留。
- 登录项注册失败时显示可理解的错误。

## 回归命令

```bash
swift build
swift test
```
