# 开发步骤

## 本地运行

1. 在项目根目录运行 `swift run PerformanceMonitor` 进行开发预览。
2. 运行 `bash scripts/build-app.sh` 生成本地 `.app`。
3. 运行 `open dist/PerformanceMonitor.app` 启动完整模式。
4. 菜单栏出现仪表图标，面板首次显示在桌面左下角，之后恢复上次拖动位置。
5. 首次通知授权可接受或拒绝，不影响基础监测。

开发预览不是标准 `.app` 包，因此会自动停用系统通知和登录启动。

## 构建与测试

```bash
swift build
swift test
```

## 工作流程

1. 修改前确认需求、风险和影响范围。
2. 修改源码和对应文档。
3. 更新当天 `开发日志`。
4. 执行构建与测试。
5. 检查 `git diff`，确保没有无关修改。
6. 提交一次说明清晰的 Git commit。
