# 指标定义

| 指标 | 定义 | 刷新 |
| --- | --- | --- |
| CPU | 用户、系统、nice 时间占总 CPU tick 的比例 | 2 秒 |
| 内存 | active + wired + compressed 占物理内存比例 | 2 秒 |
| 磁盘 | 用户主目录所在卷的已用空间比例 | 2 秒 |
| 网络 | 非回环接口累计收发字节的时间差 | 2 秒 |
| 电池 | 当前容量占最大容量比例及交流电状态 | 2 秒 |
| 进程 | 按 CPU 降序，内存作为次排序的前 6 个进程 | 2 秒 |
| GPU | 当前版本无稳定公开接口，显示暂不可用 | - |
| 温度/风扇 | 等待签名后的只读辅助程序 | - |

历史趋势只保存 CPU 和内存分钟均值；每次采样通过 SQLite UPSERT 更新当前分钟。
