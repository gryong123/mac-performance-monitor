# 技术架构

## 技术栈

- SwiftUI：仪表盘、设置和菜单栏界面。
- AppKit：桌面层窗口、窗口定位和屏幕变化监听。
- Swift Charts：CPU 与内存趋势。
- SQLite：按分钟聚合的 7 天本地历史。
- ServiceManagement：登录项开关。
- UserNotifications：持续高负载通知。

## 模块

- `SystemMetricsProvider`：系统指标采样。
- `SensorProvider`：温度和风扇的可替换只读接口。
- `MetricsStore`：刷新节奏、状态发布、历史和告警协调。
- `HistoryStore`：SQLite 建表、聚合写入、查询和清理。
- `AlertManager`：阈值判断、连续采样和通知冷却。
- `DesktopWindowController`：桌面层面板和左下角定位。

## 数据流

系统 API → `MetricsProvider` → `MetricsStore` → 界面、SQLite、告警。

所有系统采集失败都必须返回安全空值，不得阻止应用启动。
