# 产品需求

## 产品目标

为 macOS 用户提供一块可自由放置、低打扰且容易读懂的电脑性能监测面板。

## 第一版范围

- 首次在主屏幕左下角显示，距离可用区域 16pt。
- 支持自由拖动并记住位置，不支持缩放。
- 展示 CPU、内存、磁盘、网络、电池、高占用进程。
- GPU、温度、风扇保留展示位置；没有可信数据时明确显示“暂不可用”。
- 每 2 秒采样，按分钟聚合并保存 7 天。
- 支持 1 小时、24 小时、7 天趋势。
- 连续 3 次超过阈值后告警，15 分钟内不重复发送通知。
- 菜单栏支持显示、隐藏、设置、刷新和退出。

## 不在第一版

- 结束进程、远程监控、云同步。
- 调整风扇、处理器频率或其他系统参数。
- Mac App Store 分发、签名、公证和自动升级。
