# 设计规范

## 布局

- 面板尺寸：360×684pt。
- 高度增加时保持面板顶部位置，内容向下展开；触及屏幕边缘时自动保持可见。
- 默认位置：主屏幕可用区域左下角，边距 16pt。
- 顶部标题区域是窗口拖动手柄；拖动后记住位置，尺寸固定，不提供缩放。
- 圆角：22pt；内部卡片圆角：13pt。
- 间距遵循 4pt/8pt 网格。

## 视觉

- 使用 macOS 系统材质，自动跟随浅色和深色外观。
- 数值使用等宽数字，减少刷新时的视觉跳动。
- 进程或应用内存不足 1GB 时显示 MB，达到 1GB 后自动切换为一位小数的 GB。
- 正常使用薄荷绿，注意使用橙色，过高使用红色。
- 状态不能只依赖颜色，必须同时显示文字或图标。

## 可访问性

- 所有指标提供 VoiceOver 标签。
- 控件使用系统标准组件和键盘操作。
- 尊重“减少动态效果”系统设置。
- 正文与背景对比度遵循 WCAG AA。
