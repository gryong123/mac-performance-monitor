# 权限与安全

## 当前版本

- 通知权限：用于持续高负载提醒，拒绝后不影响监测。
- 登录项：由用户在设置中控制。
- 不安装管理员辅助程序。
- 只读访问 `AppleSmartBattery` 的电池温度属性。
- 不读取或写入 SMC。
- 不结束进程，不修改风扇、频率和电源设置。
- 为支持桌面层窗口拖动，应用只监听鼠标按下、拖动和松开坐标；仅在指针位于面板顶部时处理，不记录点击内容。

## 只读辅助程序接入标准

后续接入 CPU/GPU 核心温度和风扇时必须满足：

1. 主应用与辅助程序均完成代码签名。
2. 使用 XPC 且接口仅返回传感器读数。
3. 校验调用方签名与固定 Team ID。
4. 不暴露任意 SMC key 读写能力。
5. 安装前用大白话说明管理员权限用途。
6. 授权失败时继续运行其他功能。
7. 完成威胁建模、权限失败和卸载测试后才能启用。
